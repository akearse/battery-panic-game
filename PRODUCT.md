# Game Boy Arcade

## Platform
web

## Purpose
A static arcade hub for Battery Panic, Pattern Matching, SOAP, and Matching, playable on desktop and touch devices.

## Constraints
Preserve game logic, controls, scoring, audio and visual designs. Plain HTML/CSS with minimal dependencies. Reuse the existing repository and GitHub Pages deployment. Publishing requires explicit user approval.

## Brand
Premium retro Game Boy aesthetic, responsive cartridge collection and consistent navigation.
